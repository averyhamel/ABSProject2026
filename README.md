# ABSProject2026
An R &amp; Shiny web application analyzing MLB's 2026 Automated Ball-Strike (ABS) challenge system. Explores team/player challenge efficiency, missed opportunities, and leverage costs through OLS/logistic regressions, Monte Carlo simulations, and an interactive dashboard.
